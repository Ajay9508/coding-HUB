# Coding Hub

Coding Hub is a Vite/React frontend with a small Express API. The current authentication and dashboard data are local demo data, so the app can run without a database or external credentials.

## Run locally

Install each workspace's dependencies once:

```powershell
npm.cmd --prefix frontend install
npm.cmd --prefix backend install
```

Start both services from this directory:

```powershell
npm.cmd run dev
```

Then open http://localhost:5173. The API health endpoint is available at http://localhost:5000.

On macOS, Linux, or Windows Command Prompt, use `npm` instead of `npm.cmd`.

## Checks

```powershell
npm.cmd run lint
npm.cmd run build
```
